Install in 4 steps

No installer, no daemon — just an app and a Finder extension.

Download & move to Applications. Grab the zip from the latest release and drop Go2ShellNext.app into /Applications.
Clear the Gatekeeper flag (the app is ad-hoc signed):xattr -cr /Applications/Go2ShellNext.app
Launch once, then enable the Finder extension:
System Settings → General → Login Items & Extensions → Extensions → File Providers → Go2ShellNext
Add the toolbar button: hold ⌘ and drag Go2ShellNext.app from /Applications onto the Finder toolbar. Done — click it anywhere.

Build it yourself

One script, standard toolchains — no Node, no Rust.

git clone https://github.com/neekin/go2shellNext.git cd go2shellNext ./build.sh # → build/Go2ShellNext.app
